# NoteTaker - Personal Note Management Application

A modern, responsive web application for managing personal notes with a beautiful user interface and full CRUD functionality.

## 🌟 Features

- **Create Notes**: Add new notes with titles and rich content
- **Edit Notes**: Update existing notes with real-time editing
- **Delete Notes**: Remove notes you no longer need
- **Search Notes**: Find notes quickly by searching titles and content
- **Auto-save**: Notes are automatically saved as you type
- **Translate Notes**: Translate the current note content into Traditional Chinese without changing the saved note
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Modern UI**: Beautiful gradient design with smooth animations
- **Real-time Updates**: Instant feedback and updates

## 🔧 Local Development Setup

### Prerequisites
- Python 3.11+
- pip (Python package manager)
- A Supabase project

### Installation Steps

1. **Clone or download the project**
   ```bash
   python -m venv venv
   ```

2. **Activate the virtual environment**
   ```bash
   source venv/bin/activate
   ```

   Remark: On Windows, use `venv\Scripts\activate`

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Create the tables**
   Run the SQL in the [Database Schema](#-database-schema) section in your Supabase project's SQL Editor.

5. **Configure the server**
   Create a `.env` file in the project root:
   ```dotenv
   SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   SUPABASE_KEY=YOUR_SERVICE_ROLE_KEY
   ```
   Find the project URL and service role key in the Supabase dashboard. Keep the service role key on the Flask server only: never include it in browser code or commit `.env`. The app does not use a PostgreSQL connection URL.

6. **Run the application**
   ```bash
   python src/main.py
   ```

7. **Access the application**
   - Open your browser and go to `http://localhost:5001`

## 📡 API Endpoints

### Notes API
- `GET /api/notes` - Get all notes
- `POST /api/notes` - Create a new note
- `GET /api/notes/<id>` - Get a specific note
- `PUT /api/notes/<id>` - Update a note
- `DELETE /api/notes/<id>` - Delete a note
- `GET /api/notes/search?q=<query>` - Search notes
- `POST /api/notes/translate` - Translate unsaved or saved note content; send `{"content":"Hello"}` and receive `{"translation":"你好"}`

### Request/Response Format
```json
{
  "id": 1,
  "title": "My Note Title",
  "content": "Note content here...",
  "created_at": "2025-09-03T11:26:38.123456",
  "updated_at": "2025-09-03T11:27:30.654321"
}
```

## 🔒 Database Schema

### Notes Table
```sql
create table if not exists public.note (
   id integer generated by default as identity primary key,
   title varchar(200) not null,
   content text not null,
   created_at timestamptz not null default now(),
   updated_at timestamptz not null default now()
);

create table if not exists public."user" (
   id integer generated by default as identity primary key,
   username varchar(80) not null unique,
   email varchar(120) not null unique
);

alter table public.note enable row level security;
alter table public."user" enable row level security;
```
The server uses a service role key to access these tables; RLS blocks direct anonymous access. Existing local `database/app.db` records are not migrated or deleted. Newer table changes require manual SQL migrations.

## 🚀 Deployment

The application is configured for easy deployment with:
- CORS enabled for cross-origin requests
- Host binding to `0.0.0.0` for external access
- Persistent Supabase Postgres database

The Flask API itself has no authentication or per-user note isolation. Do not expose it publicly for sensitive or multi-user data without adding access controls. Supabase Auth is not included in this database-only change.

## 🔧 Configuration

### Environment Variables
- `FLASK_ENV`: Set to `development` for debug mode
- `SECRET_KEY`: Flask secret key for sessions
- `SUPABASE_URL`: Required Supabase project URL
- `SUPABASE_KEY`: Required server-side service role key; keep private
- `OPEN_ROUTER_KEY`: OpenRouter API key required for translation (may be set in a root `.env` file). The system prompt is in `prompts/translate_prompt.md`.

### Database Configuration
- Create the `note` and `user` tables with the SQL above before starting the app
- The Supabase SDK handles database requests; no local SQLite database is used
